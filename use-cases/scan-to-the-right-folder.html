Document management

From phone scan to the right folder, named and indexed

A scan on the phone arrives in an inbox folder; one instruction routes it to its proper place, with a proper name and a metadata file.

Replaces
manual filing, a cloud drive as inbox
Built with
a scanning app, folder sync, a routing script and an AI runbook
In numbers
thousands of documents routed; new before old, receipts to their day

The situation

Scanning is easy. Filing is where it stops: the scans pile up in an inbox, named scan_0047.pdf.

What I built

The phone syncs scans to an inbox folder. One instruction to the AI — route the inbox — follows a written runbook: recognise the document, find its date, give it a readable name, put it in the folder of that day, and write a small metadata file next to it. A button on my desk starts it.

The structure underneath

The AI does not decide where things go. The runbook does — a written set of rules the AI follows and I can improve. The AI is the hands; the rules are the head.

Start on a Build Day

Bring ten scans. Write the naming rule and the filing rule on one page, then let the AI apply it and correct it where it fails.

Concepts behind it

  • Runbooks — A repeatable procedure written down so a task is done the same way every time.
  • The Calendar Is the Spine — One time-axis is the backbone of a second brain — everything dated hangs off it.
