Syncthing

Continuous file sync between your own devices, without a cloud in between. How scans and photos get from my phone to the right folder.

The Syncthing Foundation

What it is

Syncthing is open-source software that keeps folders in sync between your own devices (phone, laptop, home server), directly and encrypted, without storing anything on someone else's cloud.

How I use it

Every device has a few shared folders with a clear job. A scan made on my phone lands in a scanner folder on the laptop within seconds, where a routing script files it in the right day folder. The laptops keep their working folders in sync the same way.

On a Build Day

Many small-company tools start with "how does the file get there?". A shared folder is often the simplest answer: no upload screen, no account, just a folder that fills itself.

Watch out

Sync is not backup. A file you delete on one device disappears on the others too, so keep a real backup next to it.

Concepts behind it

  • Document Vault — Plain files in a deliberate shape that both you and AI can navigate.
  • The Calendar Is the Spine — One time-axis is the backbone of a second brain — everything dated hangs off it.
  • Deliberate Simplicity — Make each part as plain as it can be without losing what matters — reuse only the fraction you actually need, and strip the rest.
